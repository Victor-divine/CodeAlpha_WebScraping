Project Title: CodeAlpha Web Scraping 
Task Overview :This repository contains the output and documentation for Task 1 of the CodeAlpha internship. 
The objective was to handle HTML structure and web navigation to extract structured retail product data from a target e-commerce sandbox environment.
Tools Used : (Octoparse). A visual, no-code web automation and data extraction tool used to parse web elements and handle automated pagination.
Target SourceURL: (http://books.toscrape.com/)  
Process & MethodologyHTML Parsing: Leveraged the tool's auto-detect feature to identify repeating product containers 
and isolate specific data fields (titles, pricing, and stock availability)
Web Navigation: Configured automated pagination rules to navigate across multiple catalog pages sequentially.
Extraction & Export: Harvested the structured data records and exported them into a clean local file format for downstream analytics.
Files Included sales_dataset.csv: The raw extracted dataset containing product attributes
